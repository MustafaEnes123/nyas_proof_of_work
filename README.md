## 2. Website Theme & Aesthetic Vision
The UI/UX design departs from the cold, sterile "cyberpunk" tech aesthetics. Instead, it focuses on organic warmth, reliability, and tactile feedback.
* **Color Palette:** "Earthy & Minimalist" — Base tones of Oatmeal/Beige, accented with Mocha, Walnut, and soft off-whites. 
* **Texture:** A subtle, continuous noise/grain overlay on the background to simulate high-quality recycled paper or a physical engineering blueprint.
* **Haptic & Living Animations (Micro-interactions):**
  * **Living Background:** Abstract, soft shapes (blobs) that slowly pulse and breathe in the background.
  * **Magnetic Elements:** Buttons and interactive cards that subtly pull the user's cursor toward them.
  * **Tactile Clicks:** Buttons that mimic physical resistance—depressing with visual weight and a slight screen-shake (haptic illusion) when toggled.
## 3. Platform Architecture (Main Sections)
The website will follow a clean, single-page application (SPA) flow or a minimalistic multi-page structure divided into three core sections:
### I. Home
* **Hero Section:** A bold, typography-driven entrance featuring the title: *"New York Academy of Sciences 2026-2027 | Proof of Work"*.
* **Atmosphere:** As the user moves the cursor, the beige background reacts with gentle, fluid ripples.
* **Call to Action (CTA):** A seamless scroll prompt leading into the "Tools" section to explore the interactive challenges.
### II. Tools (The NYAS Challenge Simulations)
This is the core technical showcase. The 3 NYAS challenges are gamified into interactive web tools.
* **Tool 1: BrainTech (Neural Sync Interface)**
  * *Concept:* A visualizer demonstrating Brain-Computer Interface (BCI) logic.
  * *Interaction:* A chaotic web of nodes (representing brain signals). When the user clicks and holds the "Calibrate" button, the chaotic nodes snap into a perfect, geometric neural network aligning with the cursor. It represents turning thought into structured, actionable data.
* **Tool 2: Misinformation & AI in Public Health (AI Fact-Checker)**
  * *Concept:* A dynamic search and verification engine.
  * *Interaction:* A prominent, elegant **Search Box**. Users can type a mock health claim (e.g., "Drinking bleach cures viruses"). Upon hitting enter, a scanning animation runs, and the tool outputs a "Trust Score," citing mock scientific sources and flagging AI-generated hallucinations. It showcases NLP/Fact-checking architectural logic.
* **Tool 3: Climitizing Infrastructure (Green Retrofit Mapper)**
  * *Concept:* A geo-spatial simulation tool for retrofitting.
  * *Interaction:* Integrated with the **Google Maps API**. The user types in an address (or clicks a random major city). The map zooms in, applies a custom dark/brown styling overlay, and generates a mock "Retrofit Potential Report" for that location (e.g., Solar viability, HVAC upgrade ROI, and green rebates).
